### Reusable metadata and export presets

- Import your existing presets: Lightroom Classic metadata presets and export presets (`.lrtemplate`), XMP metadata templates, and the app's own `.lcmeta` / `.lcexport` files, through File ▸ More Imports ▸ Import Profiles & Presets…, drag and drop, the Metadata panel's Preset menu or the Export dialog's Import…. Fields and settings with no counterpart are named in the message instead of stopping the import.
- Metadata presets now hold the creator's contact details (job title, address, city, state, postal code, country, phone, email, website) besides creator, copyright, copyright status, usage terms and info URL. Apply one to all the selected photos in one undoable step; rename and export presets from the Preset menu.
- Exported JPEG, TIFF, PNG and other files carry the contact details with the rest of the metadata; the Export dialog's Metadata section adds Copyright & Contact.
- Export presets keep the destination folder along with format, size, quality or file-size limit, file naming and metadata settings, and can be renamed, exported and imported from the dialog's preset column.
