# 0.9.5

The changes since [0.9.4](0.9.4.md). After each item, the matching upstream pull request: `(↑ #n)` means the
maintainer of this fork opened it upstream, `(⇠ #n)` means it was ported from an upstream PR, and `(no PR)`
means there is none (the change is in the fork's own Classic layout or a fork issue with no upstream counterpart).

The catalog format is unchanged (version 13). The starting look moves from version 13 to 15, so raws without edits
get a fresh starting render once.

## Highlights

- **Scopes that read like a grading suite:** the histogram, Waveform, RGB Parade and Vectorscope sit on a
  near-black well with an amber graticule, and their traces add up and glow where more of the photo sits. The
  Waveform overlays red, green and blue instead of a grey luminance trace; the Vectorscope has degree ticks and
  bracketed colour targets. Fork #335. (no PR)
- **Histogram pinned above the Edit panel:** in Develop the histogram stays at the top of the right panel while the
  controls scroll under it; slider names are a size smaller and right-aligned against their tracks. Fork #336. (no PR)
- **Export dialog in Lightroom Classic's layout:** wider and resizable sideways; presets in a column on the left
  (Add / Remove); sections in Classic's order, each folding with a summary on its header (Image Sizing, Output
  Sharpening, Metadata and Watermarking start folded; the choice is remembered). **Choose folder later**
  (`destinationMode: "chooseLater"`) asks for the folder when the export starts and is the default for a first
  export. Fork #327. (no PR)
- **A hardening pass across the app:** the control channel, device sync, SFTP, plug-in requests, downloads,
  tethering and the file parsers each lost a way to crash, hang or be misled by hostile input (listed under
  Fixes). Fork #308, #311, #320, #325, #330.

## Library

- **Single-photo rename:** with one photo selected, Rename opens a single-photo dialog pre-filled with its current
  name and keeps the file extension. Thanks @deunderscorepaul. Fork #321. (no PR)
- **A TIFF or JPEG beside a raw reads its own sidecar:** a file imported next to a raw of the same stem now reads
  `<file>.xmp`, not the raw's `IMG_0001.xmp` (it used to inherit the raw's rating, label, keywords and develop
  settings). Fork #304. (⇠ #1924)
- **Imports, collections and Custom Order:** an imported suspected-duplicate copy gets a content key of its own;
  Lightroom smart collections keep their aperture band and their RAW rule excludes DNG; a drop in a descending
  Custom Order lands where it was dropped. Fork #330. (no PR)

## Develop

- **DNG starting tone keeps the lens corrections:** a DNG whose camera preview is lens-corrected is fitted against a
  lens-corrected proxy, so its starting tone matches the preview. Thanks @radialmonster. Fork #304. (⇠ #1545)
- **Canon HDR-PQ CR3s no longer open too dark:** a CR3 with no embedded JPEG starts from the median Canon camera
  tone instead of the default curve (about 13 L* brighter). Thanks @radialmonster. Fork #304. (⇠ #758)
- **Double-click finishes Guided Upright:** as it finishes a crop; only Return did before. Fixes fork #297.
  Fork #305. (no PR)
- **Lens profiles:** a chosen lens with no focal length reports `noFocal` instead of `chosen`; a downloaded lens
  database is parsed once; stale lens profiles refresh even with the Optics section folded. Fork #331. (⇠ #930)
- **Masks and Dehaze:** auto masks are flipped once with the photo and Background follows an embedded Subject
  matte; Dehaze keeps its transmission floor. Fork #330. (no PR)

These three ports (#1924, #1545, #758) are also listed in the 0.9.4 changelog, but they merged after 0.9.4 was
published and first ship in this release.

## Interface

- **Wider slider tracks:** adjustment rows give most of the panel width to the slider track, with a narrower label
  column and a tighter value readout. Thanks @deunderscorepaul. Fork #317. (no PR)
- **Sync menu on the cloud icon:** the cloud icon in the top bar opens **Peer-to-Peer Sync…** and **Immich…**, each
  going to its Settings page. Fork #329. (no PR)
- **Edit in External Editor:** a worker that fails to launch shows a toast; editors are found by absolute path and
  by numeric AppImage versions. Fork #330. (no PR)

## Fixes

- **Navigator on first launch:** opening the app straight into Develop no longer leaves the Navigator empty until
  the Library is visited. Fork #334. (no PR)
- **The library lock is released at once on close:** a child process that hasn't started yet can no longer keep a
  closed library locked. Fixes fork #332. Thanks @clydecbrown. Fork #333. (no PR: ported from upstream's fix for its issue #680)
- **An older release no longer drops your newer edits:** opening a library made by an older release marks its
  catalog with the new format straight away, so the older release refuses it instead of opening it and silently
  losing fields it doesn't know (such as a cleared GPS position). A catalog that can't be marked (a full disk, a
  read-only catalog) isn't opened and is left unchanged. Thanks @clydecbrown. Fork #303. (no PR)
- **X swaps the crop orientation again:** in the Crop tool, X turns the frame between landscape and portrait; it had
  swapped twice and left the frame unchanged. Fixes fork #293. Fork #306. (no PR)
- **Crop rotation** no longer jumps 360° when started on the box's left side. Fork #330. (no PR)
- **Mirrored AVIF files display the right way round:** an AVIF whose container mirrors the picture (`imir`) was
  flipped on the wrong axis; it now reads the property as HEIC, libheif and libavif do. Fork #308. (no PR)
- **Credentials files stay readable after an update:** saving wrote the wrong key-derivation parameters, so a file
  written under other costs could not be decrypted after its first update. Fork #308. (no PR)
- **Actions and publishing:** a file of more than 1,000 Actions is an error instead of being cut short (and saved
  that way); republishing with a new extension no longer deletes the sidecar it just wrote. Fork #308. (no PR)
- **Control channel:** `count`, `steps` and `size` arguments are range-checked instead of letting one request run
  the app out of memory; a second app on the same control port no longer replaces the first one's token file (now
  written atomically); a connection must authenticate within 10 s, an idle one closes after 15 min, and
  unauthenticated connections can't take the slots authenticated clients need; bad `id` / `ids` arguments, mask and
  spot targets and fractional or negative indices are errors instead of acting on the active photo. Fork #308,
  #320, #330. (no PR)
- **Malformed images:** a file claiming zero width or height is refused as malformed instead of crashing; a keyword
  with thousands of levels keeps its first 128 instead of overflowing the stack; XMP drops XML-illegal characters;
  shared TIFF child IFDs and multi-string ASCII tags are kept; CR2 slice widths and CRW heap walks are bounded.
  Fork #308, #320. (no PR)
- **Exports and publishing keep same-name photos apart:** with Overwrite, two photos of one export that get the same
  name no longer replace each other (the second gets `-2`); Hard Drive publish does the same. Keymap and book
  exports refuse a path that is a catalogued photo's original or sidecar. Fork #320, #325. (no PR)
- **Network:** a custom place-name download address is parsed and its real host checked; a plug-in can't inject
  HTTP headers through CR/LF; truncated downloads are rejected and downloads have an overall deadline; Immich warns
  when a server uses unencrypted http, and an empty deletion list resolves nothing (it had resolved every queued
  deletion). Fork #320, #325, #326. (no PR)
- **SFTP host keys are confirmed, not trusted on first use:** gallery upload and SFTP publishing refuse a server
  whose host key isn't pinned yet, before any password or key is sent; Check Host Key in the Web module shows the
  fingerprint to confirm, and a changed key still aborts before login. Fork #325. (no PR)
- **Device sync hardened against hostile LAN hosts:** incoming connections are capped, unpaired devices can only send
  small messages, handshakes and pairing replies have deadlines, and a failed first pairing reply no longer blocks
  later pairings. Fork #320. (no PR)
- **Tethering keeps the card copy until the download is safe:** with "delete from card" on, a shot is removed from
  the camera only after the local file is flushed and verified. Fork #325. (no PR)
- **Rendering:** a zero-width crop no longer makes grain NaN; no colour-noise specks in shadows; grain and Texture
  match between preview and export; float sources aren't treated as clipped in merges; large GPU blurs stay within
  the driver's time limit; oversized raws are an error rather than an abort; per-site black levels keep clipped
  highlights neutral. Fork #320. (no PR)
- **Video:** with the GPU on, H.264 exports of clips using a LUT profile or a feathered mask grade those frames on
  the CPU, so the movie matches the preview; a timelapse's partial file is removed when finishing fails late.
  Fork #325, #330. (no PR)
- **Web module:** Preview in Browser opens the generated gallery page again on the desktop. Fork #325. (no PR)
- **Auto-write XMP covers capture time, trim and poster:** changing them now rewrites the sidecar, so a later folder
  sync no longer puts the old value back. Fork #325. (no PR)
- **Smaller fixes:** saving through a symlink keeps the link; the map tile cache and plug-in store write atomically;
  `run-action --connect PORT` works; keymap import is all-or-nothing; book export shows in the activity stack;
  extending a large selection is fast; slideshow fit-to-music timing is right with repeat on. Fork #320. (no PR)
