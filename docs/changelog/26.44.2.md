# 26.44.2

## Library

- **Plug-ins add a tool's files to the library:** a `libraryAdd` permission lets a plug-in add a file a tool made from a photo (`library.add {path, from, stack?, album?}`): only from the folder of that photo's original or below it, stacked on the photo as Edit In does, and in an album that holds it; a file the library has already is read again when it changed, as Reload from Disk does, and nothing is listed twice. Commands and their prepare steps learn the Library source they were started from (`source`: an album, smart album, folder, All Photographs or another view; `plugin.run` and `plugin.prepare` take one to replace it). Host feature `libraryAdd`; the `program-tools` example adds what its program made.

## Import, export and formats

- **Lightroom Classic export preset import:** `.lrtemplate` export presets whose settings use unprefixed keys (`format`, `jpeg_quality`, `size_doConstrain`, `outputSharpeningOn`, `embeddedMetadataOption`, `renamingTokensOn`, `tokens`, `collisionHandling`, `useWatermark`, etc.) or carry a dormant 16-bit depth alongside JPEG now keep their supported settings, populate the Export dialog on import, and list any unsupported settings in both the import toast and the Export dialog.

## Updater and security

- **Windows zip copies update themselves:** a copy unpacked from the portable zip unpacks the new zip beside the
  program, swaps its files in (renaming the running program aside, which Windows allows) under a locked manifest,
  and starts the new version once the app has ended (it waits on a pipe the old process holds). The previous files
  stay until the new version is up; one that doesn't come up is undone at its next start. Any failure during the
  swap puts the previous files back. Whether the MSI installed a copy is now asked of Windows Installer
  (`MsiEnumClientsW` and `MsiGetComponentPathW` on the app's component, through the new `lcc-winmsi` crate), so a
  zip copy without `portable.txt` no longer gets the MSI; a copy under Program Files is never swapped.

## From upstream

- **Fixes ported from the weekly upstream review:** DNG `WhiteLevel` written as LONG for float DNGs, Canon CR2 slice geometry validated, DNG opcode byte counts checked without overflow, face index caches over 1 GiB read, signed numbers refused in URL ports, `Content-Range` and `Content-Length`, ZIP entries with inconsistent sizes refused, EXIF time zone offsets limited to 18 hours, and a library lock removes only the note it wrote.
