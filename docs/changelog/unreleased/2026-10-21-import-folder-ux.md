## Fixes

- **Folder drops finish:** a folder dragged onto the window goes through the same scan and import review as File ▸ Import from Folder…, so the import starts and completes, and errors are shown.
- **Imported folders by name:** the Folders list no longer spells out every folder from the disk down to an imported folder; it shows the folder's name (full path on hover) and tells same-named folders apart by their parent folder.
