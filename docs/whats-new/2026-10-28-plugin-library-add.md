### Plug-ins add what your tools made
- A plug-in that sends photos to a tool, such as a raw converter, can now add the files the tool made to your library:
  stacked on the photo each came from, and in the album you sent them from. It's a permission you tick in the Plug-in
  Manager, and it only adds files from the photo's own folder.
- When the tool writes over a file it made before, the library reads it again, as Reload from Disk does.
