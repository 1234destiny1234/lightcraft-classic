# 0.9.4

## Develop

- **AI Denoise says why it's greyed out:** for a photo it can't use, the Detail panel says why under the switch and
  on hover: a raw that opens as its embedded preview (such as a Nikon High Efficiency NEF) names the decoder's
  reason, and a JPEG or other non-raw file says AI Denoise works on raw files only. Thanks @endthestart. (no PR)
- **Calibrated camera colour:** a per-photo choice (Profile ▸ Calibrated camera colour) to start a raw without matrices of its own from the camera database's spectral matrices instead of a look fitted to its JPEG. The decode options (this, Remove Hot Pixels and the camera profile) travel together in `media::LoadOptions`, so a source is decoded again only when an option that changes it changes. Thanks @good-news-everyone. Upstream PR #2222. Fork (no issue)
- **Import your own camera profiles (.dcp):** a person's own DNG camera profiles, one default per camera and one chosen per photo, with the tone fitted to the camera JPEG when a profile has none; XMP looks import like `.cube` profiles. Nothing is shipped or used as a test fixture. Thanks @metelkinn. Upstream PR #2074 (without its offline web app). Fork (no issue)

## Library

- **A cleared location stays cleared:** saving a sidecar removes the GPS position cleared in the app while the sidecar still states that position (catalog format 13); one another program wrote since is kept. Completes the earlier port of upstream PR #2088. Thanks @jkalkstein. Fork (no issue)

## Import, export and formats

- **Export presets for the web:** Instagram Feed, Instagram Story / Reel, Web / Portfolio and Full Resolution Master. Thanks @eliets2. Upstream PR #2209. Fork (no issue)
