# 0.9.4

The changes since [0.9.3](0.9.3.md). After each item, the matching upstream pull request: `(↑ #n)` means the
maintainer of this fork opened it upstream, `(⇠ #n)` means it was ported from an upstream PR, and `(no PR)`
means there is none (the change is in the fork's own Classic layout or a fork issue with no upstream counterpart).

The catalog format moves from version 12 to **13** (a cleared location is remembered so a sidecar can't bring it
back).

## Highlights

- **UI overhaul:** every develop slider takes one row (name, track, value), so a panel shows about twice as many.
  Every top-level menu has 15 rows or fewer, with related items in submenus, and there is a new Metadata menu;
  command ids and shortcuts are unchanged. Dialogs share one form layout, and Settings has a category sidebar.
  Fixes fork #281, #266, #264, #218. Fork #294. (no PR)
- **Panel toggles:** a button at the right of the top bar hides the module bar, and a new icon in the right tool
  strip folds the right panel away. Presets is now a right panel like Edit and Crop. Fork #300. (no PR)
- **Calibrated camera colour and your own camera profiles:** Profile ▸ Calibrated camera colour starts a raw from
  the camera database's spectral matrices, and you can import your own DNG camera profiles (`.dcp`), one default
  per camera and one per photo. Thanks @good-news-everyone and @metelkinn. Fork #290. (⇠ #2222, ⇠ #2074)
- **Latest upstream merged:** 85 upstream commits, listed below. Fork #299.

## Develop

- **AI Denoise says why it's greyed out:** for a raw that opens as its embedded preview (such as a Nikon High
  Efficiency NEF) the Detail panel names the decoder's reason; for a JPEG or other non-raw file it says AI Denoise
  works on raw files only. Thanks @endthestart. (no PR)
- **Export presets for the web:** Instagram Feed, Instagram Story / Reel, Web / Portfolio and Full Resolution
  Master. Thanks @eliets2. Fork #290. (⇠ #2209)

## Library

- **A cleared location stays cleared:** saving a sidecar removes a GPS position cleared in the app; one another
  program wrote since is kept. Completes the earlier port. Thanks @jkalkstein. Fork #290. (⇠ #2088)
- **The filmstrip highlights every selected photo,** not only the active one. Fixes fork #187. Thanks @wstock.
  Fork #292. (no PR)
- **The filter pill no longer covers the Info Overlay,** and a setting hides it in Develop. Fixes fork #266.
  Thanks @deunderscorepaul. Fork #292. (no PR)
- **A file imported beside its raw reads its own sidecar:** a TIFF or JPEG arriving next to a raw of the same
  name no longer takes the raw's `IMG_0001.xmp` rating, label, keywords and develop settings. (⇠ #1924)
- **Settings ▸ Folders:** every configurable folder in one place. `--memory` sessions now truly write nothing (no
  `ui.json`, no crash sentinel). Fixes fork #164, #169. Thanks @wstock. Fork #288. (no PR)

## Import, export and formats

- **TIFF:** WhiteIsZero grey images (scanner and fax output) no longer open as negatives, and 1-, 2- and 4-bit
  TIFFs open. Fork #300. (no PR)
- **PSD and text:** the borrowed PhotoCraft crates recover files with damaged merged image data and break over-long
  words properly; FilmCraft is updated. Fork #295. (no PR)

## Sync and updates

- **A side that collided no longer loses its edit:** when both devices edit the same photo, both versions are
  kept on both sides. Fork #296. (no PR)
- **Sync discovery** uses the service `_chromaforge._tcp`, following the Android package; new
  [peer sync design doc](../peer-sync.md). Fork #298. (no PR)
- **Updater on macOS:** "Include pre-releases" now finds pre-releases, and the startup check shows an available
  update. Fixes fork #289. Thanks @deunderscorepaul. Fork #291. (no PR)

## From upstream

- **Crop drags start in the zone the cursor showed** at the press, so handles are easier to grab. (⇠ #2046)
- **Print:** Page Options print page numbers, page info and crop marks. (⇠ #1903)
- **Cameras:** Hasselblad FFF colour from the embedded 3FR header (⇠ #1919); Canon EOS R6 Mark II alias
  (⇠ #1935); X-Trans CMOS 4 bodies take the X-T3's spectral matrices (⇠ #2224); AI Denoise on 102 MP Bayer raws
  (⇠ #1884).
- **Formats:** TIFF strips and tiles over 128 MiB (⇠ #1989) and faster TIFF chunk handling (⇠ #2151); JPEG XL
  and HEIF size limits (⇠ #1893, ⇠ #1894); opaque 8-bit exports drop the redundant alpha (⇠ #1691).
- **Lightroom and XMP import:** luminance ranges stay open at white, unmapped local sliders are reported
  (⇠ #1844); out-of-range GPS (⇠ #1838) and zero or negative ISO (⇠ #2040) are ignored; forbidden XML characters
  are stripped from sidecars (⇠ #2144); merged develop settings stay in range (⇠ #1960).
- **Robustness:** face index records stay aligned after a failed append (⇠ #2150); catalog snapshots with an
  out-of-range seq are refused (⇠ #2149); stricter URL, colour and rename parsing (⇠ #2091, ⇠ #2083, ⇠ #2035);
  model downloads time out the name lookup (⇠ #1778).
- **Interface:** merge dialogs remember their last settings (⇠ #1898); hovering a profile shows the applied one
  (⇠ #2070); aperture and focal search at f32 precision (⇠ #1845); localized Info Overlay notices (⇠ #1416),
  zh-Hant wording (⇠ #2105) and a Georgian symbol fix (⇠ #2235).
