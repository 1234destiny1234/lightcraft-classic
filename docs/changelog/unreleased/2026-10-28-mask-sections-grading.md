## Features

- **Masks: folding sections, Color Grading, a bin on each row:** a mask's sliders are grouped in sections that fold (Light with the Curve, Color, Color Grading, Effects, Detail); Color Grading works inside a mask (Shadows, Midtones, Highlights and Global hue, saturation and luminance, CPU and GPU); hovering a mask row shows a bin that deletes it.
