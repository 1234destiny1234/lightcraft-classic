### Batch edits while importing

- The Import screen has an optional Batch edits section: everyday sliders (Light, Vibrance,
  Saturation, Clarity, Texture, Dehaze, Sharpening, Grain, Vignette) set on every photo the import
  adds, after its XMP sidecar and preset, as one Import adjustments step. Save as Preset keeps a
  recipe for later; photos the library already has are left alone.
