### Imported folders by name, and folder drops that finish

- The Folders list shows an imported folder under its own name instead of a row for every folder from the disk down to it; the full path is shown on hover. Folders listed side by side with the same name add the name of the folder each is in, as in "trip (2024)".
- A folder dragged onto the window now imports the way File ▸ Import from Folder… does: it is scanned with progress and the import review opens. Before, the drop could sit without ever finishing.
