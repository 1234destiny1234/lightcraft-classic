# 0.9.3

A prerelease (0.9.2 was built but not published, so this includes it). Updates are now signed: from this release on, the app installs an update only when the release's
checksum list carries a valid signature. Also three bundles of open upstream pull requests (cameras and formats,
user-facing fixes, and Tier 2 features), keyword and histogram improvements, and an interface font size setting, plus the latest upstream merge (network shares keep working; see Upstream merge).

## Develop

- **The histogram counts only the photo:** the blank border a lens correction or perspective transform leaves no
  longer shows in the histogram, vectorscope and clipping indicators as a spike of light grey. Thanks @endthestart.
  Fork #211, fork #234. (no PR)
- **Waveform and RGB Parade:** two more histogram views show the photo's tones column by column, as one luminance
  waveform or as red, green and blue side by side. Thanks @endthestart. Fork #242. (no PR)

## Library

- **Several values per filter-bar picker:** the Camera, Lens and Keyword pickers take more than one value, and a
  photo with any of them is shown. Thanks @endthestart. Fork #213, fork #235. (no PR)
- **`library.facets`:** lists each metadata field's values among the photos in view with how many photos have each,
  the counts Metadata filter columns need. Thanks @endthestart. Fork #218, fork #244. (no PR)

## Interface

- **Empty keyword set shows its slots:** under Keywording, a keyword set with nothing in it yet shows its nine
  empty slots instead of a sentence about them. Thanks @endthestart. Fork #220, fork #236. (no PR)
- **Keyword suggestions in a grid:** under Keywording, up to nine suggestions sit in three equal columns, lined up
  with the keyword set above them. Thanks @endthestart. Fork #222, fork #240. (no PR)
- **Lighter Edit icon:** the sliders icon has short ticks instead of round handles, so it weighs the same as the
  other line icons. Thanks @endthestart. Fork #208, fork #243. (no PR)
- **Right column buttons fill its width:** Sync Metadata / Sync Settings and Previous / Reset share the column's width
  like Import… and Export… do on the left. Thanks @endthestart. Fork #221, fork #239. (no PR)
- **Interface font size:** choose **Tiny**, **Small**, **Medium**, or **Large** in **Settings ▸ Interface ▸ Appearance** to scale interface text across panels, menus, and dialogs. Fork #252. (no PR)

- **Join the Discord:** the Help menu and the About window link the project's Discord. (no PR)
- **Contributors are this project's own:** About ▸ Contributors lists the people who opened pull requests on this
  repository, with one line crediting upstream's contributors. (no PR)

## Updater and security

- **Portable copies update from the portable zip:** a copy with `portable.txt` beside it downloads the portable zip to
  unpack over itself, instead of the MSI, which installed the app somewhere else. Thanks @endthestart. Fork #229, fork
  #237. (no PR)
- **Updates install only with a valid signature:** a release's `SHA256SUMS.txt` is signed with a key pinned in
  `brand.toml`, and the app installs a download only when that list is signed, lists the file with a matching
  SHA-256 and names the offered version. A build without a key checks for updates and links to the release page.
  Thanks @clydecbrown. Fork #179. (no PR)

## Development

- **Release notes, one file per change:** What's New entries are files in `docs/whats-new/` and changelog entries
  files in `docs/changelog/unreleased/`, so pull requests no longer conflict over them. The app's build joins What's
  New with upstream's `docs/whats-new.md`, `cargo xtask notes --release <version>` gathers the changelog, and
  `cargo xtask notes --check` (part of `ci`) checks both. Thanks @clydecbrown. (no PR)
- **`photo.sourceReport`:** says how each original is read before any edit (sensor data or the embedded preview,
  where its starting colour and tone come from, the lens correction that applies by itself), for comparing renders
  and for bug reports. Thanks @endthestart. Fork #241. (no PR)

## Upstream merge

- **Upstream merged (13 commits):** float image samples that are not finite are clipped safely, capture-time shifts
  keep the time zone, search words with an unknown field prefix are plain text, Assisted Culling bursts across
  midnight at month end, offline reverse geocoding at longitude 180, only photo file types reach the system opener,
  and XMP sidecars are written only beside an existing original. (⇠ #2071, ⇠ #2146, ⇠ #2099, ⇠ #2095, ⇠ #2061,
  ⇠ #2135, ⇠ #2175, ⇠ #2199)
- **Network shares keep working:** upstream now follows a Lightroom catalog's originals only on this computer or on
  the share the catalog itself is on. The fork keeps following originals on any network drive or share (mapped
  drives, UNC paths, SMB/NFS mounts) wherever the catalog is; only device paths and URLs are refused. (no PR: fork
  difference)
