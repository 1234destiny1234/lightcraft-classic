### Edit In asks which file to edit
- Edit in PhotoCraft and Edit in Other Editor (menu, shortcut or right-click) first ask what the editor gets: a copy with your adjustments, a copy of the original file, or the original itself.
- Edit a Copy and Edit Original are offered for JPEG, TIFF, PNG, PSD and WebP files; a raw is always edited as a copy with adjustments. On a PSD or TIFF, Edit Original is preselected.
- "Don't ask again" keeps your choice; Settings ▸ External Editing ▸ Edit In changes it or turns the question back on.
