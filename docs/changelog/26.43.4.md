# 26.43.4

The changes since [0.9.6](0.9.6.md). The first release numbered by week: `vYY.WW.B` (ISO week-year, ISO week, the
release's number within that week), so this is the fourth release of week 43 of 2026, after 0.9.4, 0.9.5 and
0.9.6. The catalog format is unchanged (version 13).

## Release builds and CI

- **Week-based versions:** releases are now numbered `vYY.WW.B`: the ISO week-year, the ISO week and the release's number within that week. The tag, file names and every package (MSI, Android, macOS, Linux, Flatpak) carry the same version, and each release compares as newer than the last, so 0.9.x installs update to it. See `docs/versioning.md`. (no PR)
- **GPU heal-spot check:** the windowed heal spot's CPU/GPU check allows Metal's rounding on a few pixels and holds the mean ten times tighter instead. Fork #388. (no PR)
