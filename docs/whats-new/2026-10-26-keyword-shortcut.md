### A keyword shortcut of several keywords

- Metadata ▸ Set Keyword Shortcut… (⌘⌥⇧K / Ctrl+Alt+Shift+K) takes several keywords separated by
  commas; ⇧K adds them all to the selected photos, or removes them when every photo has them.
- The Keyword List's menu has Use This as Keyword Shortcut and marks its keywords with a +; a
  photo's context menu has Add Keyword with them.
