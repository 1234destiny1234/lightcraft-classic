### Remove tool unified stroke overlays and mode differentiation

- Continuous brush strokes in the Remove tool render unified, organic outer outlines via Marching Squares isoline extraction on an 8-bit mask buffer, replacing overlapping circle wireframes.
- Canvas indicator pins display mode icons (Heal, Clone, Remove, Content-Aware) and persist between canvas and right-panel edits.
- Selected spot controls and context menus allow editing mode, size, feather, opacity, refreshing donor sources, and deleting spots independently.
