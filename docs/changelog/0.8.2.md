## Faces

- **Face models run wholly on the GPU:** activations stay on the device between layers and faces are batched, so
  YuNet, SFace and AuraFace are 3–4× faster than on the CPU; Settings ▸ Faces shows the device and can keep them on
  the CPU, the scan's pace limits GPU use, and the GPU check shows in the activity stack. Fork #35. (↑ #1663)
## Features

- HDR display output: on an HDR display (macOS EDR, Windows with HDR on), an HDR edit shows its highlights above SDR white, up to what the display can show, while the interface stays at SDR white; SDR displays look as before. The HDR button's note that the window shows the SDR rendition now appears only when the display really isn't showing HDR. `--hdr-probe` reports what a machine offers; checked on Windows 11 / RTX 4090 and on Linux (KDE Plasma, Wayland) (#47). (no PR)

## Fixes

- **Crop & Straighten:** the crop box stays put and upright while the photo turns and slides beneath it, as in
  Lightroom, and straightening or moving no longer re-renders the photo on every step. Fork #60. (↑ #1699)
- **The Navigator stays in place:** in Library and Develop its panel is pinned at the top of the left column and the
  panels below it scroll under it — the loupe's level presets and the way back to the photo stay in reach however far
  the column is scrolled — as in Lightroom Classic. Fork #76. (no PR)
- **Typing a slider value:** clicking a slider's value opens the field however long the click is held (a slow
  click used to close it again), and dragging the value sideways scrubs it, as in Lightroom Classic. Fork #59. (↑ #1687)

## Improvements

- **Sync Settings like Lightroom Classic:** Photo ▸ Develop Settings ▸ Sync Settings… (Shift+Cmd/Ctrl+S) opens
  Synchronize Settings, which can now carry single Basic Tone sliders (e.g. only Exposure). Create Version loses
  that shortcut. Fork #61. (no PR)
## Fixes

- **HDR edits' SDR rendition keeps its highlights:** thumbnails, the Navigator, SDR exports and the loupe on SDR
  displays roll an HDR edit's highlights off smoothly into white instead of clipping them; SDR edits are unchanged.
  Fork #69. (↑ #1697)
- **Sharpening Radius and Detail work:** Develop ▸ Detail ▸ Sharpening is now an unsharp mask at the Radius (in the
  photo's own pixels, so previews and exports match) and Detail damps or keeps halos; before, both sliders did
  nothing and sharpening boosted mid-scale texture. Ships as process V4: older photos look as before until Update to
  Current Process. Port of radialmonster's upstream change (upstream #757; user report, Nikon Z5II). (⇠ #762)

- Import finds a sidecar whose photo extension or `.xmp` differs in case (`DSC_1.nef.xmp`, `DSC_1.Xmp` beside
  `DSC_1.NEF`) on case-sensitive disks, so its rating and crop come in; Move takes it along. Fork #43. (↑ #1686)
- **Folded panels stay folded:** a saved panel layout the app can't restore no longer stops the settings being saved
  for the session (and so at every launch); the original file is kept aside and everything else keeps being saved.
  Fork #44. (no PR)

## Upstream merge

This release merges upstream's `main` (its integration "batch 35", upstream #1682: 71 commits since the last
merge). Every item below came from upstream; issue numbers are upstream's.

### Develop and viewing

- Nikon Z 6II, Z 8 and Z f NEFs use the camera's own distortion correction. (upstream #1682)
- HDR merges keep the reference frame's lens correction. (upstream #1682)
- Heal and Clone spots with Feather at 0 no longer draw black pixels on their radius; spots at 0% opacity change
  nothing. (upstream #1682)
- The all-masks overlay shows the union of the masks, not only the last one. (upstream #1682)
- A zoomed view with Dehaze keeps its haze estimate while panning and dragging sliders, and a full-size raw is no
  longer copied once more after the colour model (faster zoomed edits). (upstream #1682)
- The Before/After button no longer lights up for Show Original (`\`) (#1497); the loupe's filter pill is evenly
  inset (#1645). (upstream #1682)

### Library, import and files

- Edit ▸ Select Only Active Photo (⌘/Ctrl+Shift+D). (upstream #1682)
- In Compare, ⌘/Ctrl- and Shift-clicks on the filmstrip change the selection without replacing the pair.
  (upstream #1682)
- Clearing the filters empties the search field too (#1648); an import ends showing its first photo (#1446);
  Synchronize Folder in the Local folder menu; Recently Deleted lists deleted Local photos (#1430). (upstream #1682)
- Thumbnails and stand-ins decode the smallest embedded JPEG that covers them (a 0.3 MB JPEG instead of 5.6 MB on
  an A7R VI), and a raw whose embedded preview can't be read still gets a thumbnail (#1448). (upstream #1682)
- Scans, imports and sidecar writes no longer build a table of the whole library first (large libraries start
  sooner). (upstream #1682)
- Face pictures in the People view come from the embedded preview and are kept in the thumbnail cache (#1440).
  (upstream #1682)
- Lightroom Classic catalogs whose tables are still all in the `-wal` file open; ARW6 files are described from the
  whole file. (upstream #1682)
- DNG export and Convert to DNG no longer repeat the camera make in the model name (#840). (upstream #1682)
- **Portable mode:** a `portable.txt` (or `<binary>.portable`) file next to the program keeps settings, logs and
  models in a data folder beside it (#1200). (upstream #1682)
- Canon EOS RP CR3 verified pixel for pixel. (upstream #1682)

### Reliability (never crash)

- Damaged catalog snapshots are repaired on open instead of crashing or hanging later; open / new library is
  refused while an import runs (#1509); moved originals are re-checked before deletion (#1500); name reservation
  falls back to an exclusive create where hard links are unavailable (#1503). (upstream #1682)
- Fixed panics or hangs for: defringe amounts past the sliders, huge spot sizes (#1519), zero-size and sliver crops,
  tone-curve points between close neighbours, `mask.move` with a huge delta, NaN black levels, very long export
  strips, enlarged exports (capped at 512 MP, memory checked first), preset zips that unpack too far, BigTIFF IFDs
  with huge entry counts (#1516), NEF / PEF Huffman predictor overflow (#1515), truncated PEF streams (#1514), RAW
  TIFFs with missing chunks (#1513), raws with two samples per pixel (#1511), non-finite denoise pixels, bad ONNX
  LeakyRelu alphas (#1530) and SAM weight shapes (#1529). (upstream #1682)
- The preview disk cache ignores symlinked shard folders (#1504); downloads refuse an https → http redirect (#1531).
  (upstream #1682)
- MCP in connect mode no longer resends a request whose reply was lost; it reports the outcome as unknown (#1526).
  (upstream #1682)
- Malformed settings groups in Copy / Paste / Sync Settings are refused with a message. (upstream #1682)
- The Windows installer ends with a completion page after install, repair and uninstall (#892). (upstream #1682)
- The interface decides on error kinds (missing model, cancelled) instead of English error text, a step towards
  translated errors (#1046); the SAM 3 dialog opens the configured model folder and keeps the setup when that
  fails. (upstream #1682)

### Translation

- Brazilian Portuguese: AI Denoise translated, plurals and six strings fixed. (upstream #1682)

### Kept from the fork instead of upstream

- Zoomed views: the fork's tiled region renderer stays; upstream's zoom-window tests (incl. the 1:1 window with the
  screen profile, #1365) and the `ZOOM=` mode of the `drag_latency` example were not taken.
- Catalog: the fork's catalog stays; upstream's snapshot repair, exclusive-create reservation and Recently Deleted
  fix were ported by hand. The fork keeps refusing the largest photo id outright.
- Portable mode and the DNG writer follow `brand.toml`: the data folder and the `<binary>.portable` marker are named
  after this app, and DNGs are marked `<app> DNG 2`; bare app-name Software tags (this name or a previous one) still
  read as the older sensor-anchored CFA layout.
- Sync Settings keeps the fork's single-control sync (`controls`) on top of upstream's group validation; Rename
  Photos stays in the Library menu.
- **Clicking the tool in use:** Develop's tool strip is radio-style, as Lightroom Classic's is. Clicking Edit, Crop,
  Masking — the tool already open — closed the panel instead, and Develop with no editing panel is Library's, so the
  click dropped the user back into the grid; it now leaves everything as it is. A tool's shortcut and the strip's
  context menu still close it, and closing one no longer leaves Develop. (no PR)
