### A roomier Export dialog, laid out like Lightroom Classic's
- The Export dialog is wider, and you can drag its edge to make it wider still (handy with a large interface font); it remembers the width.
- Presets are listed in a column on the left: click one to load it; Add saves the current settings as a preset, Remove deletes the user preset picked.
- The settings follow Lightroom Classic's order (Export Location, File Naming, Video, File Settings, Image Sizing, Output Sharpening, Metadata, Watermarking, Post-Processing). Each section folds from its header, which says what it is set to. Export Location, File Naming and File Settings start open; Image Sizing, Output Sharpening, Metadata and Watermarking start folded; what you open or fold is remembered.
- Export to ▸ **Choose folder later** asks for the folder when the export starts, also for presets saved with it. A first export starts with it, rather than a folder picked for you.
- Slider names in dialogs (Limit file size, Resolution, the watermark margins) sit in the label column with the other rows instead of being cut short.
