### Import warnings in a window, not a wall of text
- When photos come in with XMP settings from another editor that can't be applied, the import's toast now says how
  many in one line, and an Import Warnings window lists them grouped by reason, with counts. Each group can select
  its photos, and the full list can be copied or saved as text. File ▸ More Imports ▸ Import Warnings… opens it
  again. Before, every photo got its own line in a toast that covered the window and was gone in eight seconds.
