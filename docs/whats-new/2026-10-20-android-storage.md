### Android: folders read in place

- With "All files access" (asked once at first start; Settings ▸ Folders ▸ Device storage asks again), a folder you pick on the device's own storage is read where it is instead of being copied.
- Files and folders that still have to be copied (from a cloud service or an SD card) show in the activity stack and can be stopped. Picking the same document again reuses its copy, and copies no photo in the library uses any more are deleted at start.
- Picked files whose names have no extension are recognised by their type.
