### Plug-ins say what they need
- A plug-in that needs features this version of {app} doesn't have is no longer installed: the install dialog
  names what's missing. If {app} is downgraded, such a plug-in stops loading but keeps its permissions and data
  for when you update again, and the Plug-in Manager can still remove it.
- A plug-in's version must now be a version number like 1.4.0. Installing an older version than the one installed
  asks first: the dialog shows both versions and an Install Older Version button.
