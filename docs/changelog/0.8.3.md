# 0.8.3

## Fixes

- **Vivid colour grading wheels:** the rim is fully saturated sRGB fading evenly to a neutral centre, instead of a muddy, washed-out disc. Fork #77. (↑ #1719)
Changes since 0.8.2. After each item, the matching upstream pull request: `(↑ #n)` means the maintainer of this fork
opened it upstream, `(⇠ #n)` means it was ported from an open upstream PR, and `(no PR)` means there is none.

## Export

- **Export next to the originals, with Lightroom's naming templates:** Export to "Same folder as original photo"
  (plus an optional subfolder; each photo of a mixed selection goes to its own folder), and a File Naming Template
  menu with Custom Name - Sequence, Filename - Sequence and the Custom Text token. Fork #80. (⇠ #996)
## Development

- **Tests never open desktop windows:** showing a file in the file manager (a manual update install) and starting
  an external editor go through a session seam that headless runs and tests record instead of spawning `xdg-open`,
  `open` or `explorer`. No issue. (no PR)

## Develop

- **The mouse wheel resizes the brush:** with the Masking brush active, a plain wheel notch over the photo grows or shrinks the brush (as `[` / `]` do) instead of zooming; Ctrl/Cmd+wheel still zooms, and Preferences → Interface → "Wheel resizes brush instead of zooming" turns it off. Thanks @deunderscorepaul. Fork #96. (no PR)
- **Clipping shown on the photo:** J / the histogram triangles paint clipped highlights red and crushed shadows blue per pixel (no more border frame), and ⌥/Alt-dragging Exposure, Highlights, Whites, Shadows or Blacks shows Lightroom's black/white clipping mask. Thanks @deunderscorepaul. Fork #94. (no PR; upstream has #995/#999 for the same, open)
- **Tidier Masks panel:** Refine Edges and Feather sit right under the overlay Opacity (shown only with a mask
  selected), and the Show all overlays toggle and Show Pins sit on the row of overlay colours, in every overlay mode.
  Thanks @deunderscorepaul. Fork #91, issue #82. (no PR)
- **The Presets panel folds away:** in Develop the panel carries the same Classic header as the Versions, History and
  Collections panels below it, and a click on that bar folds the list to the bar alone, leaving the panels below the
  room; folding it there can't leave the presets column (Shift+P) open and empty. Thanks @deunderscorepaul. Fork #75.
  (no PR)

## Library

- **Delete from Disk:** Photo ▸ Delete from Disk, or the button beside Remove in the Delete dialog, moves the photos'
  files and their XMP sidecars to the system trash (never a permanent delete) and takes them out of the library in
  one undo step; virtual copies and shared raw + JPEG sidecars are handled, a disconnected disk keeps its photos, and
  it always asks first. Scripts and agents pass `confirm: true`. Thanks @deunderscorepaul. Fork #98. (no PR)

## Platforms

- **HDR display output confirmed on macOS:** on an Apple M1 Max's built-in XDR display, HDR edits show above SDR
  white in the loupe (EDR), completing the Windows and Linux checks from 0.8.2. Fork #47. (↑ #1700)
